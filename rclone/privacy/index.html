John's rclone Backup

Privacy Policy

John's rclone Backup is a personal application used solely by the application owner to access their own Google Drive account through rclone.

Scope

Google Drive access

The application accesses Google Drive in order to upload, download, manage, verify, and restore files used for personal backups and file synchronization.

Storage

Data storage

Google account data is not collected into a separate commercial database or analytics system. OAuth credentials are stored privately on systems controlled by the application owner.

Sharing

Data sharing

Google user data is not sold, shared, or provided to third parties.

Control

Access revocation

Access may be revoked at any time through the security settings of the associated Google Account.
