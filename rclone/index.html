Personal Project · OAuth Application

John's rclone Backup

A personal OAuth application that lets rclone, running on privately operated servers, access my Google Drive for encrypted backups and file synchronization.

Privacy Policy Back to Site

Overview

Built for one operator, not the public.

This application is for personal use and is not offered as a public service. It exists so that self-hosted machines under my control can authenticate against my own Google Drive account.

There is no sign-up, no shared tenancy, and no third-party access. The only account it ever touches is the one that owns it.

Scope

What it does

  • Uploads and downloads encrypted backup archives
  • Synchronizes files between self-hosted servers and Drive
  • Verifies backup integrity and restores when needed
  • Stores its OAuth credentials privately, on owner-controlled systems
